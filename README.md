# Healthcare Readmission Analysis

## Project Overview

This project analyzes healthcare encounter data to identify patterns associated with hospital readmissions among diabetic patients. The analysis explores how patient characteristics and healthcare utilization relate to readmission outcomes.

## Business Question

What factors and utilization patterns are associated with hospital readmissions among diabetic patients?

## Tools

* **SQL / BigQuery** — data cleaning, transformation, aggregation, and analysis
* **Tableau** — data visualization and dashboard development
* **Excel** — data review and organization

## Analysis

I prepared and analyzed the dataset to examine:

* Readmission rates
* Prior inpatient visits and readmissions
* Patient age groups
* Healthcare utilization patterns
* Insurance/payment types
* Other patient and encounter characteristics

## Key Skills Demonstrated

**Data Cleaning • SQL • BigQuery • Data Analysis • Data Visualization • Tableau • Data Storytelling • Healthcare Analytics**

## Outcome

The analysis transformed raw healthcare encounter data into visual insights that highlight patterns in readmissions and healthcare utilization. The findings provide a foundation for further investigation into opportunities to reduce avoidable readmissions and improve patient outcomes.

## Project Purpose

This capstone demonstrates my ability to take a real-world dataset from **raw data to actionable insights** using SQL, BigQuery, and Tableau.
